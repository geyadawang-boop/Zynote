# 课表识别与聊天公式边界

聊天的历史消息、待发送消息、流式回复都使用共享 Markdown。该渲染器现在接入已有 remark-math/KaTeX，支持闭合的 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`。未闭合流式片段暂按文本显示，补全后自动渲染。复制与存储保留原文；不执行原始 HTML，不开启 KaTeX trust。GFM 与安全外链处理沿用。

归一化先使用独立 CommonMark parser 标记代码、链接、图片、HTML 与定义的源范围，再只转换其外部的公式。嵌套列表/引用中的代码、链接 URL/标题与图片 alt 保留；保守地不保证链接文字中的反斜杠公式渲染。常见货币 `$5 and $10` 不误配为公式，但 Markdown 的单美元写法仍有语义歧义，明确的公式建议使用闭合公式分隔符。

当前源码的三条入口能力不同：

- 聊天接口只有 content 文本，不带图片；课程聊天拖放不支持直接识别图片。
- “课表与教材→识别课表”接收文本与 IANA 时区，不直接读图片。只有星期、节次、单双周的周课表还需明确日期/学期周次规则及作息时刻表。节次不是课次，也不是几点。识别结果是草稿，核对后才保存。
- “画面识别”实际发送图片到视觉模型。提示要求先读行列标题、节次时刻对照、课程覆盖节次、周次/单双周，并区分视频定位秒数与上课时间；不编造缺少规则的日期或起止时刻。Markdown 无法无损表达合并网格，要求明确注明覆盖范围。

课表 AI 输出必须属于请求提供的课程目录，已有课次必须属于该课程；结束时间必须存在，且其偏移要与该时刻的指定 IANA 时区一致（按 DST 规则）。手工条目仍允许结束时间为空。结构检查无法证明模型的日期/章节来自原图，不能替代人工核对；目前不新增自动周课表展开或网格几何解析器。

测试用生成的 JPEG 网格及本地 HTTP stub 验证视觉请求确实含完整图片字节、选择视觉模型、携带对应约束；不是模型识别质量测试。无用户原图及实际运行软件版本，不能认定该软件与此源码同构，也不能声称三个入口的真实图片识别全部解决。独立真实图片、合并单元格、单双周及周日期正确率仍待真实样本验收。
