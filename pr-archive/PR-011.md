## 描述

## 课表与教材

- 从教务系统或手机课表截图生成可编辑的周课表。识别过程中显示进度，遇到遮挡或缺项时可以补录，核对后再保存。上传入口附有三种虚构课表示例。
- 复用智云课堂登录匹配教学班和回放，遇到同名教学班时显示教师、学期供选择。一本教材可以关联多个课次。
- 在 PDF 正文中并列查看老师、自主和 AI 批注。老师批注可追溯至智云回放中的语音转写；同一段可保留多种来源。支持文字拖选、扫描页识字、自由框选和画线，以及按页定位。预览和写入 PDF 使用一致的来源配色。

## 复现与验证

1. 打开「课表与教材」，点「查看示例」切换三种排版；上传一张课表，修正一条课程后保存并重开。
2. 在「教材划线」打开 PDF，为同一本书勾选多个课次，分别用「老师批注」「自主批注」「AI 批注」查看或添加批注，保存后重开 PDF 核对位置与颜色。
3. 已通过 `pnpm verify`、Go 和 Rust 测试、Go vet、六个 Go 核心包的竞态检测。Vitest 97 项通过，Windows 环境因符号链接权限跳过 1 项。Go 后端通过 Linux/amd64 和 macOS/arm64 交叉编译。
4. Windows x64 lite 成品通过启动和端到端测试。课表和教材的模型交互使用本地模拟响应验证；三张内置示例均为合成数据。
