## 描述

现有图标仍保留外围透明留白，缩小显示时容易显得偏小。本次先放大构图铺满画布，再统一裁切四角形成圆角。

- 收紧 SVG viewBox，将浅蓝底板铺满画布，并用同一圆角 clipPath 裁切背景和标志。
- 保留原云朵、黄色图案及渐变色，同步导出 PNG 和 16/32/48/64/128/256 像素 ICO。
- 检查各尺寸四边中点完全不透明、四个角完全透明，确认没有外围缩边。

验证（Windows x64）：
- `pnpm verify`
- `pnpm backend:test`
- `pnpm native:test --release`，14 项测试通过
- `pnpm build`
- Windows lite 打包及打包版启动检查
- 程序与安装器内嵌的六种尺寸图标均与新 ICO 一致
