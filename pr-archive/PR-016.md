## 描述

Image timetable drafts discarded visible clock times and week/odd-even restrictions, and replay matching could bind a lesson while edited restrictions or a manual selection were still pending. Preserve and display the original notes, require manual replay selection when week restrictions exist, fence stale matching responses, and validate text timetable course/lecture and timezone boundaries.

Extend the shared math renderer for model-style backslash delimiters while preserving program code, links, image metadata, currency and incomplete streams; retain safe KaTeX settings and contain wide display formulas. Render closed math/latex/tex/katex fences and independent closed formula lines inside mixed fences with KaTeX; retain remaining non-formula lines as code and show invalid LaTeX visibly. Align the imported KaTeX styles to the actual renderer (0.16.47) to fix superscript/fraction/matrix geometry; render complete mathematical expressions inside inline backticks as inline math while retaining actual programs and amounts. Append a shared math-format contract to normal chat prompts (including custom prompts) so models are asked to emit renderable LaTeX without user reminders; keep original prompt/source content and raw streamed/stored replies intact. Give remaining literal inline code a distinct token background and use the dedicated code-block foreground so preserved delimiters remain easy to distinguish from rendered formulas.

Validation: TypeScript (both configurations), Biome, contracts, 109 Vitest tests (1 skipped), full Go tests/vet, focused Go race checks, native Rust tests (16), build, and controlled light/dark browser checks passed, including identical math/code examples at 1200px and 360px with internal code-block scrolling. Local HTTP fixtures verify actual image bytes, the vision-model request path and normal-chat math prompt/raw reply persistence. The production-built App was also checked through actual history loading, composer submission, chat events and saved-history reload using local bridge stubs. Real user images and external model recognition accuracy remain unverified.
