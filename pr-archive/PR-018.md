## 描述

Subtitle correction could replace a whole source cue with a short fragment or text intended for another cue. Fresh default-prompt jobs now return to the legacy full-row protocol. A shared conservative fidelity guard retains source text with a specific uncertainty reason for detected destructive changes in live responses, cached results, checkpoint resume and publication.

Historical compact jobs retain their original prompt/fingerprint and paid progress, but every changed compact cue is quarantined to its original text for manual review. A correct processed-ID list cannot prove whether sparse patch IDs used the model's intended basis; similar cues defeat heuristic detection. We do not guess by shifting IDs, silently apply those candidates, change identity or replay paid work. Unchanged cues stay unchanged. Conflicting legacy/compact job or checkpoint histories fail closed. The unversioned DisableThinking change is withdrawn from correction requests so historical wire/digest options remain Images-only. Other upstream scheduler and diagnostics changes are preserved.

Tests reproduce fragment replacement, neighbor copying and mixed ID bases, including a high-similarity case. RPC/HTTP/DB/SRT tests verify fresh legacy default, complete source retention and no repair/replay. Historical cache fixtures use zero provider calls; partial/completed checkpoint fixtures retain fingerprint/prefix and independently verify publication quarantine. Unicode, legitimate small corrections, numbers/negation/formula symbols and bounded huge outputs are covered. The guard is heuristic, not semantic verification, and may flag legitimate corrections. Source-bound edit v3 is deferred. The earlier tiny real A/B missed these failures and is not a usable acceleration or general quality claim. No paid retest or real user-state access occurred.

Validation on upstream main `0769ac89405d37e3c12e76fa46a08cb013902cbc` plus this fix: full `pnpm verify` (244 files/177 actions), `pnpm backend:test`, native16/16 and API/learning/generationjob/app race tests pass. Later test-only additions pass focused race. A local837cue diagnostic takes about12–14ms per full guard pass; this is local resource evidence, not provider/model performance. Independent static review found no remaining P1.

Draft PR; no merge, installation or launch. PR17 was already externally merged before this fix, so this branch contains only the hotfix against current main.
