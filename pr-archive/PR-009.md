## 背景

#5 合并后，为录制决赛演示视频对研究板块（研究与工作流 / 知识会话 / 研究笔记）做了整体走查，并用真实千问（qwen3.7-plus）把之前未端到端验证的渠道逐一跑了一遍。本 PR 是走查中发现问题的修复，均为研究板块内部改动。

## 改动

**走查修复（界面与回答）**
- 带记忆建议的回答先修复 LaTeX 反斜杠与字符串内原始换行再解析；不合格的记忆建议直接丢弃，不连累回答本身
- 开始研究后自动滚动到新卡片；研究与工作流按创建时间从新到旧排列（按 `updated_at` 排会让运行中的卡片来回跳）；工作流内部步骤产生的研究不再单独成卡
- 原话核对默认显示 3 条（有问题的优先），其余可展开；笔记列表时间改为本地格式
- 研究、知识会话、研究笔记的回答用 `ui/MathMarkdown`（KaTeX）渲染公式；`MathMarkdown` 新增可选 `components` 以保留研究结果的链接处理

**边缘功能修复**
- **论文页全文**：arXiv PDF 下载走了通用 2 MB 上限，常见论文全部报“外部响应过大”。改为 PDF 单独上限 **50 MB**、总时限 **3 分钟**（`http.Client.Timeout` 包含读完响应体，只放宽大小在慢网下仍会超时）；其他外部请求保持 2 MB / 30 秒，共用客户端不被改写
- **MCP**：模型无法为所选工具填写参数时，原来整次研究失败；改为跳过该工具，写入 `mcp-skipped` 事件和范围说明。配置快照核验失败等仍按失败处理
- **记忆建议**：长字幕上下文下模型几乎从不采用“可返回 JSON”，建议从未出现（知识会话默认勾选学习记忆）。改为 Markdown 正文照常输出，末尾可附 ```` ```memory ```` 代码块；代码块写坏只丢建议、不丢回答，流式预览保持可读；仍兼容旧的整段 JSON
- 学习方法名不合规时，报错说明须为英文小写短名
- MCP 工具清单的展开箭头与工具名同行
