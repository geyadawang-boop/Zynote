## 描述

## 背景

#5 的评估报告里有几项当时标为“决赛前暂不做”：多轮研究、新增检索渠道，以及几处硬限制（长课超预算读不全、论文 64 页上限、分类建议只能看不能用、模型深度思考约 60–70 秒才开始写）。本 PR 把这些都补上，全部在研究板块内。

## 改动

**多轮研究（`backend/internal/research/rounds.go`）**
- 资料不够时，模型可以不作答，只返回一个 ```` ```need ```` 代码块请求补充：继续读取被截断的字幕到某时刻（`read`）、在知识库再检索（`search_library`）、在已勾选外部渠道再检索（`search`）、调用已选 MCP 工具（`tool`）。系统执行后带着新资料再问，最多 8 轮
- 资料足够时第一轮直接作答，耗时与原来相同
- 本地资料始终“从开头读到某处”，阅读片段仍是原文前缀，`verifyLocalTaskSources` 等核验规则不变；累计阅读 40 万字封顶，检索新增资料最多 8 份、外部结果最多 24 条
- 不会死循环：一轮没有任何新进展时，下一轮强制作答；最后一轮仍在请求则判为失败
- 每轮做了什么写进事件（界面“处理过程与来源”可见），从第二轮起列给模型，避免原样重复请求
- 抽出 `appendLocalSourcesWithCaps` / `sourceLimitations` / `callMcpTool` 供多轮复用，原有单轮路径行为不变

**新渠道：OpenAlex、维基百科（`external_reference.go`）**
- OpenAlex：每次 8 条，倒排索引还原摘要，链接优先用 DOI；与其他学术渠道一样使用模型改写的英文检索词
- 维基百科：按问题语言选 zh（`variant=zh-cn`）或 en；用 `generator=search` 一次取回导语；中文问句先去掉疑问词和虚词再检索（整句检索会命中无关条目）
- 外部结果仍最多 12 条，但改为按渠道轮流取（原来先到先得，多选渠道时排在后面的渠道会被整批丢掉）；渠道数上限改按白名单长度，超限报错改为“渠道数量无效”
- openalex 归入 papers 工具组；维基新增 `encyclopedia`（百科检索）工具组，停用网页搜索时仍可保留百科

**快速模式**
- 研究、两步工作流、知识会话可勾选“快速模式”，经 `ai.WithoutThinking(ctx)` 关闭深度思考；只对 DashScope 的 chat/completions 加 `enable_thinking=false`，其他服务商和 responses 接口不受影响
- 英文检索词改写、MCP 参数填写这类小请求始终关闭思考

**其他限制**
- 论文 PDF 页数上限从 64 改为 2000。此前超过 64 的页码会被静默丢弃，超过 64 页的论文会整篇被拒；报错拆成“超过上限”和“所选页不存在（全文共 N 页）”
- 分类建议：勾选“分类建议”的研究完成后，可在结果下方展开“把分类建议应用到知识库”。这里直接复用知识库的 `KnowledgeClassification`（生成建议 → 核对 → 保存），只列出本次研究用到的资料。列表回包为此新增 `channels` 和 `material_ids`，不含原文
