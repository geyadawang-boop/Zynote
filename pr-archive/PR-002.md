## 描述

应用图标的外层白色画布会在桌面上显示为方形；Windows 原生助手依赖 DirectML.dll，但现有构建脚本与发布资源清单没有复制该文件，可能导致原生助手无法启动。

本次改动：
- 移除 SVG 的外层白色画布，保留原图案和浅蓝圆角底板；同步更新透明背景 PNG 及 16、32、48、64、128、256 像素的 ICO。
- Windows 构建时将 Rust release 目录中的 DirectML.dll 复制到 backend/bin，并纳入安装包资源。

验证（Windows x64）：
- `pnpm verify`
- `pnpm backend:test`
- `pnpm native:test --release`，14 项测试通过
- `pnpm build`
- `pnpm smoke:go-core`，包含 Go/Rust PDF 读取检查
- PNG 与 ICO 六种尺寸的透明边角检查通过
