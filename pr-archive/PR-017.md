## 描述

Subtitle correction could accept a short edited fragment or another cue's full sentence as the replacement for an entire source cue. This hotfix withdraws compact v2 from fresh default-prompt jobs and restores legacy full-row output. A shared source-fidelity guard retains the original cue and marks uncertainty for detected destructive changes in live legacy/v2 responses, historical cache hits, partial/completed checkpoint resume and final publication. Safety detection does not trigger another provider call or reset paid progress. Existing compact identities and UNKNOWN liabilities remain authoritative; conflicting legacy/compact job or checkpoint histories fail closed.

Local regression fixtures reproduce both destructive response shapes, including nonzero absolute batch IDs. RPC/HTTP/database/SRT tests confirm full original text survives, default jobs use legacy, and repeated resume adds no HTTP. Separate legacy/v2 HTTP fixtures confirm one call each with no JSON repair; seeded historical legacy/v2 success caches sanitize locally with zero provider calls. Partial/completed checkpoint tests retain saved prefixes. Unicode, repeated source, valid small term/classifier edits, numerical/negation/formula risks and bounded large-output cases are covered. The guard is conservative heuristic damage detection, not semantic verification; valid corrections can be flagged for manual review, and token-preserving semantic errors may remain. Source-bound edit protocol v3 is deferred.

The earlier 28-row DeepSeek Flash comparison missed these destructive cases. Its historical 12.841/4.698-second batch observations do not justify usable acceleration or general correction quality. Compact is now withdrawn by default. No paid retest, desktop install/launch or real user database access was performed for this hotfix.

This PR also contains the existing durable evidence pipeline: shared two-active/four-admitted scheduler, ordered commits, attempt ledger, generation fences, exact-identity success adoption, Unicode receipts and publication audits. Default summary recipe remains v2. Default-off v3 provides bounded tree reduction and selected original-core review; unreviewed parent prose is suppressed. Experimental/default-off schema4 freezes source-bound semantic proposals and independent halo budgets. One prior real schema4 trial failed before verified publication; its cause remains unresolved and real acceptance remains blocked.

Local validation: full `pnpm verify`, `pnpm backend:test`, native16/16, API/learning/generationjob/app Go race tests, and independent static review. The 837-cue resource diagnostic uses controlled local edits and reports roughly12–14ms per full guard pass; it is not model/provider performance. LCS trims equal edges and uses a two-million-cell limit, with cheap length rejection before dynamic programming. Existing eleven native warnings remain.

PR remains draft pending checks on this exact head. Prior-head green checks do not cover the hotfix.
