## 描述

## 背景

SonarCloud `main` 分支当前有 263 项 `OPEN/CONFIRMED` 问题（5 个漏洞 + 258 个 code smell）。本 PR 先处理可安全落地的漏洞与低风险规则；认知复杂度重构量大且集中在恢复/状态机代码，另行分批处理。

## 修复内容

**漏洞**
- `backend/internal/storage/bootstrap.go`：`PRAGMA user_version` 只拼接编译期整数常量，补充 `NOSONAR` 说明。
- `backend/internal/research/runs.go`：后台研究改用 `context.WithoutCancel(ctx)`，保留请求上下文值但不随 RPC 取消。
- `scripts/release.mts`：简化版本/路径/更新元数据正则，消除超线性回溯。
- `scripts/migration-drill.mts`：手动迁移演练依赖操作者提供的 `sqlite3` CLI，补充 `NOSONAR` 说明。

**代码异味**
- 31 个 `go:S1192` 重复字面量改为包级常量。
- 14 个 `go:S978` 遮蔽预声明标识符重命名（`copy`/`real`/`close`/`cap`）。
- `go:S1186` 空函数补充平台说明。
- TypeScript/JS 低风险项：`codePointAt`、去掉无 await 的 async、`Promise.allSettled` 直接传 iterable、optional chain、`String.raw`、正则简化等。

## 暂未处理

- `src/renderer/index.html` 的 CSP `style-src 'unsafe-inline'` 是既有风险：本地 Electron 渲染层使用 React inline style，移除需要把动态样式全部改成 CSS 类/变量并做主题回归，留待单独的渲染层改造。
- `go:S3776` / `typescript:S3776` / `rust:S3776` / `javascript:S3776` 约 120 项认知复杂度。
- `go:S107` 参数过多、`godre:S8242` context 字段等结构性规则。

这些改动会触及恢复、发布、播放留存等状态机，需要单独分批重构和回归，避免一个 PR 里同时改变行为。
